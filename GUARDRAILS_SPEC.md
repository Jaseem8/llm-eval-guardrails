# Guardrail Enforcement Specification

## Defense Layers
1. **Pre-Flight Filter**: Checks for jailbreak prompts (`ignore previous instructions`, delimiter attacks).
2. **Post-Flight Filter**: Validates strict JSON syntax against Pydantic models.
3. **Factual Grounding**: Computes n-gram semantic alignment against verified context chunks.
